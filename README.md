# Voice-Assistant

* ## 1 Создаём виртуальное окружение 
    ```
    python -m venv .venv
    ```
*   ## 2 Активируем виртуальное окружение 
    ```
    python -m venv .venv
    ```
*   ## 3 Устанавливаем бибиотеки
    ```
    pip install -r requirements.txt
    ```
*   ## 4 Запускаем помошника 
    ```
    python src/main.py
    ```
